Goal:
Explain where the CPU spends time, how efficiently the hot kernels execute, and how AVX-512 + OpenMP accelerate the reduced-precision nested MLMC implementation.

Characterize how IPC/cache/SIMD-utilization drift as problem size (loop trip count) grows — a real, useful chapter finding in its own right ("does the kernel's hardware efficiency hold up as nc grows, or does something degrade — icache pressure, register spill, etc."). For this you'd want a few even levels (same branch family) spanning a range: l=0, l=2, l=4, l=6, l=8 — not just one comparison point — so you can show a trend, not a single before/after snapshot.

recommendation: pick l = 0 only. (Gile's recommendation)
