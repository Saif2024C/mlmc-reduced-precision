CORE CLOCK DURING EACH RUN
--------------------------------------------------------------------------------
Sampled from /proc/cpuinfo over the cores actually running the work, while the
benchmark was executing.  

The clock is the same at both thread counts -- marginally higher, if anything,
with 32 cores loaded.  There is no boost-to-base drop to correct for, and both
runs are already at ~3.8 GHz.
