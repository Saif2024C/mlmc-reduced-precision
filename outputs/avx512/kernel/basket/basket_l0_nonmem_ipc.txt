Non-memory IPC -- basket European level-0 kernel
N = 4,194,304, serial, mimic (Xeon Gold 6538Y+). 2026-08-25.

Counters: mem_inst_retired.all_loads / .all_stores are INSTRUCTION-retired
counters, so they are unit-consistent with "instructions" and the
subtraction (instructions - loads - stores) is exact. Both were verified
identical to L1-dcache-loads / L1-dcache-stores in the same pass, so the
earlier L1-dcache-based estimate needed no correction.

HEADLINE
  Total IPC slightly favours FP32 (1.64 vs 1.58), but NON-MEMORY IPC
  favours FP16 (1.31 vs 0.98). FP32 spends 40.6% of its instruction
  stream on loads and stores, against 17.0% for FP16. FP32 is not
  retiring more useful work per cycle, it is retiring more memory traffic.

CAVEAT
  Effective clock in this pass was 2.00 GHz (FP32) / 1.82 GHz (FP16),
  below the ~2.7 GHz seen in the kbench_perf passes, so absolute IPC here
  is not comparable with Table 4.4. Compare ratios within this run only.

  VTune (uarch-exploration, same kernels) gives the same conclusion in
  pipeline slots, with no subtraction needed:
    Memory Operations   FP32 21.9%  vs  FP16 10.0%  of pipeline slots
    FP Arithmetic       FP32 12.5%  vs  FP16 11.7%  of uops
